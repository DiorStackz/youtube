# HOOK SYSTEM

## Primary Hook Patterns

- “This was confirmed… but never explained”
- “They released this… then went silent”
- “No one can explain this”
- “This shouldn’t exist”
- “Something about this doesn’t make sense”

## Curiosity Hooks

- “At first, it looked normal… until this happened”
- “There’s one detail everyone missed”
- “This changes everything we thought we knew”
- “It only gets stranger from here”

## Authority Hooks

- “According to declassified documents…”
- “The Pentagon confirmed this in 2020”
- “Scientists still can’t explain this”

## Anti-Clickbait Rule

- Never lie in the hook
- Curiosity > exaggeration

## Hook Formula

[Strange Fact] + [Unanswered Question] + [Tension]
